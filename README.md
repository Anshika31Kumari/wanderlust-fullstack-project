# 🌍 Wanderlust - Full Stack Travel Listing Application

A full-stack travel listing web application that allows users to explore, create, edit, and manage travel property listings. The application includes secure user authentication, image uploads, reviews, and a responsive interface to provide a seamless user experience.

---

## ✨ Features

- User Registration & Login Authentication
- Create, Edit and Delete Listings (CRUD)
- Image Upload for Listings
- Review and Rating System
- Responsive User Interface
- Secure Backend using Express.js
- MongoDB Database Integration

---
